# Registro de versión inicial

Esta carpeta corresponde a la primera versión funcional del Sistema de Gestión de Solicitudes Académicas.

## Alcance
- Gestión de estudiantes.
- Gestión de responsables.
- Registro y seguimiento de solicitudes.
- Búsqueda, filtrado y reporte.

## Persistencia
SQLite mediante la biblioteca estándar `sqlite3`.

## Estado
Versión inicial pendiente de ejecución y verificación en el entorno del estudiante.

## Trazabilidad
Antes de refactorizar, guardar esta versión en Git y crear el tag `estado-inicial`.
