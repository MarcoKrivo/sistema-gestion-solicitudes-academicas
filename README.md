# Sistema de Gestión de Solicitudes Académicas — Versión inicial

## Descripción
Aplicación de consola para registrar estudiantes, responsables y solicitudes académicas, actualizar estados, asignar responsables, buscar solicitudes y generar un reporte.

## Tecnologías
- Python 3.12 o superior
- SQLite (biblioteca estándar de Python)

## Ejecución
Desde esta carpeta:

```bash
python main.py
```

La base de datos `solicitudes.db` se crea automáticamente al iniciar el programa.

## Funcionalidades
1. Registrar estudiante.
2. Registrar responsable.
3. Registrar solicitud.
4. Cambiar estado de una solicitud.
5. Asignar responsable.
6. Buscar y filtrar solicitudes.
7. Generar reporte general.

## Nota sobre esta versión
Esta es la versión base del TPI. Se conserva como punto de comparación para el diagnóstico y el refactoring posterior.
